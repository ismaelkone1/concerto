# Project General Rules

These rules apply to all phases of the project development.

## Coding Standards
- Language: English (Code, Comments, Documentation).
- Style: Strict adherence to the selected stack's best practices (e.g., Airbnb style for React, PSR for PHP).
- Type Safety: Mandatory (TypeScript strictly typed, no 'any').

## Git Workflow
- Atomic commits.
- Descriptive commit messages (feat:, fix:, docs:, refactor:).

## Documentation
- All public functions must have JSDoc/DocBlock.
- Keep the `README.md` and `docs/` folder updated at every major step.
